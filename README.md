# Project 1 - Team & Services Website

A responsive and visually focused website built using HTML, CSS, and JavaScript. The project presents a team/company profile along with its services through a simple and interactive web interface.

## 📌 Overview

This project was created as a frontend web development project to demonstrate the use of core web technologies for building a structured and responsive website.

The website includes sections for:

- Company/Project introduction
- Services offered
- Team members
- Profile information
- Visual branding and imagery
- Interactive frontend elements

## 🚀 Features

- Responsive website layout
- Clean and simple user interface
- Company/project branding
- Services section
- Team member section
- Profile section
- Interactive JavaScript functionality
- Custom CSS styling
- Image-based visual elements

## 🛠️ Technologies Used

- **HTML5** - Website structure and semantic elements
- **CSS3** - Styling, layout, and responsive design
- **JavaScript** - Interactivity and dynamic behavior
- **PNG/JPG Assets** - Logos, profiles, services, and team images
